## Overview

This is a Wine iOS driver implementation that enables running Windows applications on jailbroken iOS devices with JIT compilation support.

## Features

- **IOkit Integration**: Native integration with iOS IOKit for graphics, audio, HID devices, and USB
- **Metal Support**: Hardware-accelerated rendering using Apple's Metal API
- **OpenGL ES Support**: Fallback to OpenGL ES 2.0/3.0 for older devices
- **JIT Compilation**: Dynamic code generation with RWX memory allocation (jailbroken devices)
- **Touch Input**: Multi-touch support with gesture recognition
- **Virtual Keyboard**: On-screen keyboard with Wine integration
- **Window Management**: Native iOS window hosting for Wine windows
- **Display Support**: Multi-monitor and display configuration detection

## Requirements

### For Running
- Jailbroken iOS device (iOS 13.0 or later)
- Appropriate kernel patches for:
  - JIT memory allocation (`com.apple.security.cs.allow-jit`)
  - Sandbox removal (`com.apple.private.security.no-sandbox`)
  - Library validation bypass

### For Building (Linux Cross-Compilation)
- Linux with clang installed
- iOS SDK from https://github.com/theos/sdks
  ```bash
  git clone https://github.com/theos/sdks.git /path/to/sdks
  ```

### For Building (macOS)
- macOS with Xcode 15.0 or later
- iOS SDK (included with Xcode)

## Building

### Option 1: Linux Cross-Compilation (with theos SDK)

This allows you to compile the source code on Linux. The final linking must be done on macOS.

1. Clone the iOS SDK:
   ```bash
   git clone https://github.com/theos/sdks.git /workspace/project/ios-sdk
   ```

2. Navigate to the iOS app directory:
   ```bash
   cd dlls/wineios.drv/ios-app
   ```

3. Build using Makefile:
   ```bash
   make SDK_PATH=/workspace/project/ios-sdk clean all
   ```

4. Copy the project to macOS and run `build_on_mac.sh` to create the final IPA

### Option 2: macOS Native Build

1. Open the project in Xcode:
   ```bash
   cd dlls/wineios.drv/ios-app
   open project.pbxproj
   ```

2. Select a signing identity (or "Sign to Run Locally")

3. Build:
   ```bash
   xcodebuild -project project.pbxproj -scheme Wine \
     -configuration Release \
     -destination 'generic/platform=iOS' \
     clean build
   ```

4. Or use the build script:
   ```bash
   ./build_on_mac.sh
   ```

### Option 3: Using make on macOS

After copying from Linux:
   ```bash
   make clean && make
   ./build_on_mac.sh
   ```

## Installation on Jailbroken iOS

### Using Cydia Impactor (Sideloading)

1. Download Cydia Impactor from https://cydiaimpactor.com
2. Connect your iOS device
3. Drag the Wine.ipa onto Cydia Impactor
4. Enter your Apple ID
5. Wait for installation to complete

### Using Command Line (after jailbreak)

```bash
# Install via ssh
scp Wine.ipa root@your-iphone:/tmp/
ssh root@your-iphone
cd /tmp
unzip Wine.ipa
mv Wine.app /Applications/
respring
```

## Using Wine iOS

### First Launch

1. Launch Wine from the home screen
2. Grant permissions when prompted
3. Wait for Wine environment to initialize

### Running Windows Applications

#### Method 1: File Browser
1. Open the Wine app
2. Tap "Open" or use Files app integration
3. Select a .exe file
4. Wine will launch the application

#### Method 2: Command Line
1. Open Terminal on iOS (via SSH or app)
2. Navigate to Wine prefix:
   ```bash
   cd /var/mobile/Documents/wine_prefix/drive_c
   ```
3. Run executable:
   ```bash
   wine notepad.exe
   ```

### Configuration

Wine prefix location: `Documents/wine_prefix/`

Directory structure:
```
wine_prefix/
├── dosdevices/    # DOS device mappings
├── drive_c/       # C: drive
│   ├── windows/   # Windows system files
│   └── program files/
└── system.reg     # Registry
```

### Performance Tips

1. **Enable JIT**: The app will automatically enable JIT if available
2. **Use Metal**: Metal rendering provides best performance
3. **Close background apps**: Free up RAM for Windows applications
4. **Use landscape mode**: Better for Windows applications

## Troubleshooting

### "JIT not available" warning
This is normal on non-jailbroken devices. Wine will run but without JIT compilation, which may affect performance.

### Application crashes
- Check if the application is compatible with Wine
- Try running in software rendering mode (disable Metal)
- Check Wine debug logs in Console app

### Touch input not working
- Ensure the application window is focused
- Try tapping the status bar to regain focus

### No sound
- Check iOS system volume
- Ensure no other app is using audio

## Technical Details

### IOkit Integration

The driver integrates with multiple IOkit subsystems:

- **IOGraphics**: Display detection and configuration
- **IOHID**: Human interface devices (touch, keyboard)
- **IOUSBLib**: USB device support
- **IOAudio**: Audio device enumeration and control

### Rendering Pipeline

1. Wine renders to an offscreen surface
2. Surface data is copied to Metal/OpenGL texture
3. Texture is rendered to the UIView layer
4. Display link synchronizes with screen refresh

### JIT Implementation

On jailbroken devices, the JIT subsystem:

1. Allocates RWX memory via `mach_vm_allocate`
2. Generates ARM64 code for hot paths
3. Flushes instruction cache
4. Registers code with Wine's JIT subsystem
